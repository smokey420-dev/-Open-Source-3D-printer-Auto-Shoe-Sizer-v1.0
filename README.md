# -Open-Source-3D-printer-Auto-Shoe-Sizer-v1.0
OpenSource Shoe Sizer. 3D scaling ruins shoes. This app uses Lattice Scaling to fit any shoe STL to your foot scan without ruining thickness. Note: My printer is down, so I need alpha testers! Usage: Open Sizer.html, upload foot/shoe STLs, click Auto-Fit, and download. No data leaves your PC. License: MIT.
